KTX HÓC MÔN — STABLE PRODUCTION 101
Ngày chốt: 17/10/2026

Mục tiêu:
- Đây là bản nền Production ổn định để vận hành thực tế.
- Không xóa index.html khi cập nhật.
- Mọi thay đổi tiếp theo nên làm trên bản thử, kiểm tra xong mới thay bản Production.

Các file cần nằm trực tiếp ở ROOT GitHub:
- index.html
- manifest.webmanifest
- sw.js
- pwa-icon-192.png
- pwa-icon-512.png
- qr-form.html
- qr-config.js
- vercel.json

Cấu hình Vercel:
- Framework Preset: Other
- Production Branch: main
- Root Directory: để trống
- Build Command: để trống
- Output Directory: để trống

Khuyến nghị cập nhật an toàn:
1. Tạo bản backup online trước khi cập nhật.
2. Không tạo commit "Delete index.html".
3. Thay thế trực tiếp index.html bằng file mới.
4. Chờ Vercel deployment mới ở trạng thái Ready + Production.
5. Ctrl+F5 và kiểm tra: Tổng quan, Quản lý công nhân, Supabase, QR, Backup.
6. Nếu có lỗi, dùng Instant Rollback về deployment Stable gần nhất.
